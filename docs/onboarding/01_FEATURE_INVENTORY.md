# 01 - BẢNG KIỂM KÊ TOÀN BỘ CHỨC NĂNG HỆ THỐNG HRM (FEATURE INVENTORY)

**Hệ thống:** SIMS HRM V26.10  
**Tình trạng kiểm kê:** Hoàn thành kiểm tra đối soát 100% các màn hình và API backend  
**Quy ước vai trò sử dụng:**
- **[Admin]:** Quản trị viên hệ thống (quản lý tài khoản, cấu hình tham số, phân quyền).
- **[HR]:** Chuyên viên Nhân sự & Tiền lương C&B (người trực tiếp nhập liệu, tính công, tính lương, quản lý hồ sơ).
- **[Manager]:** Quản lý bộ phận, xưởng, chuyền (đăng ký tăng ca, duyệt phép, theo dõi chấm công cấp dưới).
- **[Employee]:** Nhân viên / Công nhân (đối tượng tra cứu, xem phiếu lương, quẹt thẻ).
